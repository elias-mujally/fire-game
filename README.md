# PROJECT ECLIPSE (2189)

**3D Open-World Sci-Fi Action RPG** built with TypeScript, Three.js, React, Tailwind CSS, and Web Audio API.

## Installation & Running

Ensure **Node.js (v18+)** is installed, then run:

```bash
npm install
npm run dev
```

Open the local development server URL (`http://localhost:3000`) in a modern desktop browser.

To create a production build:

```bash
npm run build
```

## Controls

| Input | Action |
| :--- | :--- |
| **W, A, S, D** | Move Operative |
| **Mouse** | Orbit Third-Person Camera (click viewport for Pointer Lock, or hold LMB + drag) |
| **Shift** | Sprint (consumes Stamina) |
| **Space** | Jump |
| **Ctrl / Alt / V** | Directional Evasive Dodge Roll (grants invulnerability frames) |
| **C** | Toggle Crouch |
| **Left Mouse (LMB)** | Light Melee 3-Hit Combo / Fire Active Ranged Weapon |
| **Right Mouse (RMB)** | Hold to Aim Down Sights (Ranged) / Hold to Energy Block (Melee) |
| **F** | Heavy Melee Cleave (high stagger damage) |
| **1 / 2 / 3** | Switch Weapons (`1` Eclipse Plasma Blade, `2` MK-IV Pulse Rifle, `3` Hyperion Rail Cannon) |
| **R** | Reload Ranged Weapon |
| **Q / Z / X** | Special Abilities (`Q` EMP Nova AoE, `Z` Aegis Shield, `X` Overdrive Lance Beam) |
| **Tab** | Target Lock Nearest Hostile |
| **E** | Interact (Terminals, Datapads, Supply Caches, Neural Beacons, Core Overload Pylons) |
| **H / G** | Quick-use Nanite Med-Injector (`H`) / Flux Battery Cell (`G`) |
| **I / K / J / M** | Open Tactical Menu (`I` Inventory & Forge, `K` Skill Tree, `J` Quest Journal, `M` World Map) |
| **Esc** | Pause / Resume |

## World Sectors & Progression

1. **Meridian City (South)**: Awaken outside Sub-Facility Zero, battle robotic patrols, recover logs, and decrypt the Meridian Relay Terminal.
2. **The Ashen Wastelands (Central & East)**: Traverse industrial ruins, avoid thermal magma hazards, fight mutated stalkers, and defeat **The Iron Colossus** to recover the Omega Override Key.
3. **NEXUS Research Complex (North)**: Unlock the laser security gate, navigate glowing obsidian monoliths, trigger Core Overload Pylons, and confront **NEXUS Prime**.
